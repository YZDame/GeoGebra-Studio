2D 与 3D 原生交互

GeoGebra Classic

由官方 GeoGebra Classic 引擎驱动，支持等比例坐标轴、可拖动点、滑块、9 套配色主题与深浅色模式。

7 种格式即刻导出

GGB · TikZ · PDF

页面内直接下载可二次编辑的 HTML、GGB、PNG、SVG、PDF、XML 与清洗后的 TikZ，并支持 Asymptote 与 TSQX。

几秒内安装到你常用的 AI 客户端。

Node.js ≥ 22.12

支持 macOS、Windows 与 Linux，基于 GPL-2.0-or-later 开源。

1. 通用 Agent Skill 安装（推荐）

适用于 Claude Code、Codex、Cursor、ChatGPT 等所有支持 Agent Skills 的客户端。

Claude Code · Codex · Cursor
npx skills add YZDame/GeoGebra-Studio --skill geogebra-studio

2. 在 Codex 当中安装

运行下方命令后新开一个 Codex 会话即可生效。

npx @lydt/geogebra-studio@latest install

3. 在 DeepSeek Harness 当中安装

在桌面端打开「插件 → 添加插件」粘贴包名，从左侧栏打开即可在对话旁实时作图。

dsh-geogebra-studio

4. Grok Bot 与 Cursor

Grok Bot 可直接发送下方指令安装；Cursor 可用上方通用命令，或将仓库克隆至 ~/.cursor/plugins/local/geogebra-studio。

Grok Bot · Cursor
从 https://github.com/YZDame/GeoGebra-Studio 安装 geogebra-studio 技能

使用方法

安装后直接向 AI 描述作图需求，或上传题目文档与参考截图。例如：

画一个三角形和它的外接圆，顶点可以拖动。
01

描述或上传题目

在任意支持的 AI 客户端输入描述，或上传题目 PDF 与截图。

02

拖动点与继续修改

打开生成的 HTML 即可拖动点和调整参数，也能继续让 AI 迭代修改。

03

保存与多格式导出

关闭前可下载修改后的 HTML 或 GGB，或一键导出 PNG、SVG、PDF 与 TikZ。
