一句话出图

把题说成点和线。技能写成命令，生成一个新的 HTML。已有的文件不会被盖掉。

拖动修改

在图里拖自由点。改动只留在这一页。关页面前把 HTML 或 GGB 下载下来。原来的 JSON 不动。在新标签打开九点圆

导出到讲义和课件

GGB 和 HTML 拿回去还能改。PNG、SVG、PDF 贴进讲义。TikZ 是已经画好的图。XML 可以再转成 Asymptote。TSQX 里混着 Asymptote，不是纯 TSQX。

  • GGB构造还在，手改也在。
  • HTML里面包着 GGB，能再打开。
  • PNG / SVG / PDF讲义、课件用这些。
  • TikZ / XMLTikZ 是静态图。XML 给下一步。

安装

电脑上要有 Node.js 22.12 或更新的。打开图时要联网，浏览器去加载 GeoGebra 官方引擎。Claude Code、Cursor、Codex、WorkBuddy，认 Agent Skills 的，都用同一条命令。没有安装器，就把 skills/geogebra-studio 整个目录拷进去。只拷 SKILL.md 不够。

  • 安装npx skills add YZDame/GeoGebra-Studio --skill geogebra-studio
  • Codex 插件npx @lydt/geogebra-studio@0.6.0 install
  • generate--input --workspace --output
  • preview--input --workspace
  • exporttsqx、asymptote 或 tikz
  • doctor看 Node 和运行时在不在。

问答

还要再装一遍 GeoGebra 吗？

不用。网页打开时，引擎从 GeoGebra 自己的地址加载。

会盖掉我的文件吗？

不会。只写新文件。要另一份就加 --output。

拖完会自己存上吗？

不会。关页面前下载 HTML 或 GGB。

预览怎么是白的？

会拦外部脚本的文件预览，打开就是白的。用 preview 给的本机地址，或用 Chrome、Safari 直接打开 HTML。「GeoGebra failed to load」是引擎没起来。「Command N failed」是那一条命令要查。
