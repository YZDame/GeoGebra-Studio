问答

要单独安装 GeoGebra 吗？

不用。打开 HTML 时，浏览器联网加载官方引擎。生成文件本身可以离线。

会覆盖我的文件吗？

不会。生成器只写新文件。要另一份时加上 --output。

拖动会自动保存吗？

不会。关闭前下载当前 HTML 或 GGB。原来的 JSON 保持不动。

预览为什么是空白？

文件预览面板可能拦住引擎脚本。用 preview 给出的本机地址，或用 Chrome、Safari 直接打开 HTML。GeoGebra failed to load 是引擎没起来。Command N failed 是构造命令要检查。

许可是什么？
