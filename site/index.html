安装

支持 macOS、Windows 与 Linux，需要 Node.js 22.12 或更高版本。

Node.js ≥ 22.12

1. 通用安装（推荐）

适用于 Claude Code、Codex、Cursor 等支持 Agent Skills 的客户端，需要 Node.js 22.12 或更高版本。

Claude Code · Codex · Cursor
npx skills add YZDame/GeoGebra-Studio --skill geogebra-studio

2. 在 Codex 当中安装

运行命令，然后新开一个 Codex 会话。需要 Node.js 22.12 或更高版本。

npx @lydt/geogebra-studio@latest install

3. 在 DeepSeek Harness 当中安装

在桌面端打开「插件 → 添加插件」，粘贴下面的包名即可安装。安装后从左侧栏打开 GeoGebra Studio 即可在对话旁使用画布。

dsh-geogebra-studio

4. Cursor 与 Grok Bot 安装

Grok Bot 可直接发送下方指令让其安装技能；Cursor 可使用上方通用命令，或将仓库复制到 ~/.cursor/plugins/local/geogebra-studio（也可仅复制 skills/geogebra-studio/ 到 ~/.cursor/skills/）。

Cursor · Grok Bot
从 https://github.com/YZDame/GeoGebra-Studio 安装 geogebra-studio 技能

使用方法

安装后，直接向 AI 提出作图需求，或上传题目文档、参考图。例如：

画一个三角形和它的外接圆，顶点可以拖动。
01

描述或上传题目

在任意支持的 Agent 中描述需求，或直接上传题目文档与参考截图。

02

拖动点与继续修改

打开生成的页面即可拖动点、调整数值，也可以继续让 AI 迭代修改。

03

保存与多格式导出

关闭或刷新前，请下载当前 HTML 或 GGB 保存修改，或导出 PNG、SVG、PDF、TikZ。
