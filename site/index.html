文档 GitHub 颗星

AI Agent + GeoGebra = ？

用 Agent Skill 生成可交互的 GeoGebra 图形，并导出为 GGB、PNG、PDF、TikZ、HTML 等格式。

安装

1. 通用安装

适用于支持 Agent Skills 的客户端，需要 Node.js 22.12 或更高版本。

npx skills add YZDame/GeoGebra-Studio --skill geogebra-studio

2. 在 Codex 当中安装

运行命令，然后新开一个 Codex 会话。需要 Node.js 22.12 或更高版本。

npx @lydt/geogebra-studio@latest install

3. 在 DeepSeek Harness 当中安装

在桌面端打开「插件 → 添加插件」，粘贴下面的包名即可安装。

dsh-geogebra-studio
