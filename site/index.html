GeoGebra Studio
文档 GitHub 颗星

AI Agent + GeoGebra = ？

用 Agent Skill 生成可交互的 GeoGebra 图形，并导出为 GGB、PNG、PDF、TikZ、HTML 等格式。

npx skills add YZDame/GeoGebra-Studio --skill geogebra-studio

需要 Node.js 22.12+ 和支持 Agent Skills 的客户端。

DeepSeek Harness 使用同一条 Skill 安装。在对话中调用 /geogebra-studio。
