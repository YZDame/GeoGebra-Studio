# Showcase templates

Prefer these repository examples when the user wants a striking demo, README hero, or short video take:

- Middle school, 2D: `examples/napoleon.json` — Napoleon's theorem
- High school, 2D: `examples/nine-point-circle.json` — nine-point circle and Euler line
- University, 3D: `examples/hyperboloid-ruled.json` — ruled one-sheet hyperboloid
- Advanced / promotional 3D: `examples/calabi-yau.json` — Fermat quintic projection inspired by Calabi–Yau popularizations

Copy the JSON into the workspace (or point `generate` at the absolute path), keep free points free so dragging remains interesting, and preserve the color hierarchy. For `calabi-yau.json`, say clearly that it is a multi-patch projection of a Fermat quintic slice for visualization, not a computed Calabi–Yau metric.

After generation, use the default loopback preview workflow from `SKILL.md`. For video, record dragging `A`/`B`/`C` on the 2D examples and a slow orbit on the 3D examples.
